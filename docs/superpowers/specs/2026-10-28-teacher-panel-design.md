## เป้าหมาย

## 1. โหมดเสียง

`SpeechQueue` มีค่าใหม่สองค่า เปลี่ยนได้ระหว่างทำงาน:

- `mode`: `'spell'` (ค่าเริ่มต้น พฤติกรรมเดิม) หรือ `'word'`
- `spell_max_cells`: int ค่าเริ่มต้น 2

`prepare_page()` เก็บ `(line_id, cell_index) → word_index` และ `word_index → จำนวนเซลล์` ของหน้าไว้
`EnterCell` ไม่ต้องเปลี่ยน (หาคำของเซลล์จากแผนที่นี้แทน เทสต์เดิมไม่ต้องแก้)

กฎใน `handle()` (ใช้ event ล่าสุดเหมือนเดิม):

| event | `spell` | `word` และคำ ≤ `spell_max_cells` | `word` และคำยาวกว่า |
|---|---|---|---|
| `EnterCell` เสียงคำพร้อม | พูดชื่อเซลล์ | พูดชื่อเซลล์ | ไม่พูด |
| `EnterCell` เสียงคำยังไม่พร้อม | พูดชื่อเซลล์ | พูดชื่อเซลล์ | พูดชื่อเซลล์ (ไม่งั้นผู้เรียนไม่ได้ยินอะไรเลย) |
| `FinishWord` คำตัวเดียว | ไม่พูด (พูดชื่อไปแล้ว) | ไม่พูด | — |
| `FinishWord` เสียงคำพร้อม | พูดคำ | พูดคำ | พูดคำ |
| `FinishWord` เสียงคำยังไม่พร้อม | ไม่พูด | ไม่พูด | ไม่พูด |

`FinishWord` เกิดเฉพาะเมื่อนิ้วผ่านครบทุกเซลล์ของคำ (`finger_state.py`): ยกนิ้วหรือย้ายบรรทัดกลางคำจะไม่พูดคำ
ลากผ่านช่องว่างเร็วเข้าคำถัดไป ถือว่าจบคำก่อนหน้า (ถ้าอ่านครบ) · ย้ายไปบรรทัดอื่นต้องค้าง 0.4 วินาที (`LINE_DWELL_S`)

ระหว่างอ่านไม่สังเคราะห์เสียงใหม่ (เหมือนเดิม) จึงไม่ต่อชื่อเซลล์เป็นข้อความใหม่

เปลี่ยนโหมดกลางคำมีผลกับ event ถัดไป ค่าเดิมของเซลล์ที่พูดไปแล้วไม่ย้อนกลับ

`SpeechQueue.last_spoken` เก็บข้อความล่าสุดที่ `say()` เล่น ให้ server อ่านไปแสดง

## 2. ฟังก์ชันตั้งค่า `panel_settings.py`

```python
DEFAULTS = {'mode': 'spell', 'spell_max_cells': 2, 'camera': True}

def validate(partial: dict, current: dict) -> dict      # คืน settings ใหม่ทั้งชุด หรือ raise ValueError(ข้อความไทย)
def load(path: Path) -> dict                             # ไม่มีไฟล์หรือไฟล์เสีย: คืน DEFAULTS และ log warning
def save(path: Path, settings: dict) -> None             # เขียนไฟล์ชั่วคราวแล้ว replace กันไฟล์เสียเมื่อไฟดับ
def apply_settings(speech, path: Path, partial: dict) -> dict  # validate → ตั้งค่า speech → save → คืน settings
```

- ไม่รับ field ที่ไม่รู้จัก ชนิดผิด (`True` ไม่นับเป็น int) หรือค่านอกช่วง
- ผิดข้อเดียวไม่เปลี่ยนอะไรเลย
- ไฟล์ค่าเริ่มต้น `output/panel_settings.json`
- `finger_reader.py` เพิ่ม `--speech-mode {spell,word}` และ `--spell-max-cells N` สำหรับใช้โดยไม่มีหน้าเว็บ ค่าจาก CLI ทับค่าในไฟล์

## 3. หน้าเว็บ `web/index.html`

แบบ A (สองคอลัมน์) โทนสว่าง สีหลัก `#0050DC` เดียวกับจุดเบรลล์ในหนังสือ

- ไฟล์เดียว CSS/JS อยู่ในไฟล์ ไม่โหลดอะไรจากอินเทอร์เน็ต
- แถบบน: ชื่อสถานี + ชิปสถานะ (marker, มือ, status)
- ซ้าย: ภาพ `/stream.mjpg` พร้อมสวิตช์กล้องที่มุม ปิดแล้วหยุดโหลดภาพและส่ง `camera: false`
- ขวาบน: "ใต้นิ้ว" ชื่อตัวอักษรตัวใหญ่ + คำ
- ขวาล่าง: ปุ่มเลือก สะกด / เฉพาะคำ และ [−] N [+] (1–5) ส่ง `POST /api/settings` ทันที ช่อง N จางเมื่อโหมดสะกด
- ล่าง: ข้อความทั้งหน้าแยกบรรทัด ไฮไลต์ `active_word`
- กว้างน้อยกว่า 720 px: เรียงแถวเดียว
- ดึง `/api/state` ทุก 300 ms ติดต่อไม่ได้: แถบแดง "ขาดการเชื่อมต่อ" คงค่าเดิมและลองใหม่ต่อ
- ส่งค่าตั้งไม่สำเร็จ: คืนปุ่มเป็นค่าเดิมและแสดง `error` จาก server
- โหมดจำลอง: เปิดจาก `file://` หรือมี `?demo` ใช้ข้อมูลปลอมที่นิ้วไล่อ่านไปเรื่อย ๆ และการตั้งค่าเปลี่ยนเฉพาะในหน้า
- ปุ่มใช้คีย์บอร์ดได้ มี `aria-label` และ `aria-pressed` ตัวอักษรตัดกับพื้นหลังตาม WCAG AA
