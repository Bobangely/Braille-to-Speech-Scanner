# โค้ด CV/Hybrid ที่เลิกใช้งาน

เก็บไว้เป็นประวัติจากรุ่นก่อนตัดสินใจใช้ YOLO เท่านั้น ไม่ถูกนำเข้าโดยโปรแกรมกล้อง ตัวอ่านภาพ ตัวสร้าง dataset หรือชุดทดสอบปัจจุบัน

ไฟล์ benchmark และ tests ในโฟลเดอร์นี้บันทึกพฤติกรรมของ CV เดิม ไม่ใช่คำสั่งใช้งานของ branch ปัจจุบัน หากต้องการรันซ้ำให้ใช้ revision ก่อนย้ายไฟล์ เนื่องจาก import/path บางส่วนยังเป็นโครงสร้างเก่า

ดูวิธีใช้งานปัจจุบันที่ `docs/SYNTHETIC_DATASET.md` และ `docs/YOLO_CELL_STREAM.md`
